# Resgata+ — Dinheiro Protegido

Registra o valor que a pessoa pretendia depositar/apostar.

O valor é informado livremente pelo usuário.

Exemplo:
R$ 50,00

O sistema registra esse valor como dinheiro protegido/economizado por decisão do usuário.

O Resgata+ não guarda nem movimenta esse dinheiro.
